## Using them with the exercises

**A deck comes before the exercise it covers, not after.** The exercises are written as practice for something already explained — a student who opens one cold spends the session stuck on syntax instead of the idea. Mentors decide when each one happens; students don't work ahead.

The slides and the exercises are not the same material and don't line up one to one. The exercises are the spine of the track; slides are for the front of the room before students open an editor. Where a deck covers something the exercises deliberately skip — `Scanner`, or a topic from a FIRST library — skip that section rather than teaching it. See the design decisions in the repo context file for what this track leaves out on purpose.

## Replacing them

When we write our own deck for a topic:

1. Add it here and update the table.
2. Delete the borrowed one it replaces.
3. Note in the row that it's ours.

Our own decks should follow the same rules as the exercises: robotics situations, no FIRST libraries, no `Scanner`.
