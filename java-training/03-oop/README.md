# 03 — Object-Oriented Programming

Classes, objects, and the structure that every real robot program is built on.

These three exercises are **one continuous project**, not three separate ones. Students keep extending the same files, and by the end they have a small multi-class program with the same skeleton as a real WPILib or FTC project.

| # | Exercise |
|---|----------|
| 6 | [Your First Class: Motor](06-classes-and-objects.md) |
| 7 | [Encapsulation and Composition: Drivetrain](07-encapsulation-and-composition.md) |
| 8 | [Inheritance and Polymorphism: Subsystems](08-inheritance-and-polymorphism.md) |

## Files students will end up with

```
Motor.java         a thing that spins
Drivetrain.java    four Motors working together
Intake.java        another subsystem
Arm.java           another subsystem
Subsystem.java     what all three have in common
Robot.java         the only file with main()
```

Compile with `javac *.java`, run with `java Robot`.
